## 📊 证据等级说明 / Evidence Level Guide

本仓库对每条信息标注证据等级，帮助读者判断可靠性：

| 标签 / Tag | 含义 / Meaning | 典型来源 / Typical Sources |
|:---:|---|---|
| 🟢 **高置信度** / High | 经同行评审、多次验证 / Peer-reviewed, replicated | 顶刊论文 (Nature, Science, Cell)、大型 RCT、Meta 分析 |
| 🟡 **中置信度** / Medium | 初步证据、有待验证 / Preliminary, needs validation | 预印本、动物实验、小样本试验、权威报告 |
| 🔴 **低置信度** / Low | 推测性、早期阶段 / Speculative, early-stage | 新闻报道、专家观点、概念验证 |

## 📅 更新节奏 / Update Schedule

本仓库采用 **三层信息架构** / This repo uses a **three-layer architecture**:

| 层级 / Layer | 频率 / Frequency | 说明 / Description |
|:---:|:---:|---|
| 📰 双周快报 / Bulletin | 每 2 周 / Biweekly | 追踪最新论文、新闻、产业动态 / Latest papers, news & industry moves |
| 📚 知识库 / Knowledge Base | 持续 / Continuous | 5 大板块全景参考 / Panoramic reference across 5 sections |
| 📊 半年综述 / Review | 每 6 月 / Semi-annually | 十大突破 · 置信度升降级 · 趋势分析 / Top 10, confidence tracking, trends |

- 📋 每次快报包含：新发现摘要、证据等级、来源链接
- 📊 每次综述包含：十大突破、置信度升降级、各领域趋势、前瞻预测
